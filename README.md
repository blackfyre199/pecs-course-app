# Pécs CLS 课程 App

这是为 University of Pécs – Clinical Laboratory Scientist MSc 2026/27 I Semester 制作的个人课表 PWA。

## GitHub Pages 部署

1. 在 GitHub 新建一个仓库，例如 `pecs-course-app`。
2. 把本文件夹中的所有文件上传到仓库根目录：
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `.nojekyll`
3. 打开仓库 `Settings` → `Pages`。
4. 在 `Build and deployment` 中：
   - Source 选择 `Deploy from a branch`
   - Branch 选择 `main`
   - Folder 选择 `/(root)`
5. 点击 `Save`。
6. 等待 GitHub Pages 给出网址，例如：
   `https://你的用户名.github.io/pecs-course-app/`
7. 在 iPhone 的 Safari 打开该网址 → 分享 → 添加到主屏幕。
